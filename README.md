# ZYNQEL — Telegram-бот сигналов (24/7)

Этот воркер крутит **тот же движок**, что и сайт (funding + BTC-фильтр), круглосуточно,
и шлёт сигналы (вход BUY/SELL + наблюдение) в твой Telegram-канал.

Данные берёт с Binance — **бесплатно, без ключей**. Платить нужно только за хостинг
(место, где воркер работает 24/7) — около **$5/мес**.

---

## ШАГ 1. Создать Telegram-бота (2 минуты, бесплатно)

1. В Telegram найди **@BotFather**.
2. Напиши `/newbot`, придумай имя и username бота.
3. BotFather пришлёт **токен** — длинная строка вида `7123456789:AAH...`. Сохрани.

## ШАГ 2. Создать канал и добавить бота

1. Создай канал в Telegram (например «ZYNQEL Signals»).
2. Сделай бота **администратором** канала (Manage Channel → Administrators → Add → твой бот → право Post Messages).
3. Узнай **CHAT_ID** канала:
   - Если канал публичный — это просто `@имя_канала` (например `@zynqel_signals`).
   - Если приватный — добавь в канал бота **@getidsbot** на минуту, он покажет id вида `-100123456789`, потом удали его.

## ШАГ 3. Запустить воркер на хостинге

Тебе нужен сервер, который работает постоянно. Самое простое — **Railway** или **Render**
(не требуют своего Linux, деплой через сайт). Либо VPS (Hetzner/DigitalOcean) если умеешь.

### Вариант А — Railway (проще всего, ~$5/мес)

1. Зарегистрируйся на railway.app (через GitHub).
2. New Project → Deploy from GitHub repo → выбери репозиторий, **папку `worker`** (или залей только её).
   - Если Railway просит корень — можно создать отдельный репозиторий только с содержимым папки `worker`.
3. В разделе **Variables** добавь:
   - `BOT_TOKEN` = твой токен от BotFather
   - `CHAT_ID` = `@твой_канал` или `-100...`
   - (необязательно) `POLL_MINUTES` = `5` (как часто проверять, по умолчанию 5 мин)
   - (необязательно) `SEND_WATCH` = `1` (слать наблюдение; `0` — только входы)
4. Railway сам запустит `npm start`. В логах увидишь «ZYNQEL Telegram worker запущен».
5. В канал придёт «✅ ZYNQEL бот запущен».

### Вариант Б — VPS (для тех, кто умеет в терминал)

```bash
# на сервере (Ubuntu):
sudo apt update && sudo apt install -y nodejs npm
git clone <твой-репозиторий> && cd zynqel/worker
export BOT_TOKEN="7123...:AAH..."
export CHAT_ID="@zynqel_signals"
# держим процесс живым через pm2:
sudo npm install -g pm2
pm2 start zynqel-bot.js --name zynqel-bot
pm2 save && pm2 startup   # автозапуск после перезагрузки
pm2 logs zynqel-bot       # смотреть логи
```

## Что делает бот

- Проверяет 21 монету каждые 5 минут (настраивается).
- Шлёт сигнал **только когда состояние изменилось** (не спамит одинаковым).
- **Основные монеты** (BTC, ETH…): и LONG, и SHORT.
- **Мемы/альты** (PEPE, SHIB…): **только SHORT** (как на сайте — лонг отключён).
- Без данных (история funding или режим BTC не загрузились) — молчит, не выдумывает.

## Честно про частоту

Сигналов **немного**, особенно на спокойном рынке (это правильно — движок ждёт сетап).
Бот не сделает сигналов больше, он просто избавит от необходимости сидеть в приложении —
напишет в канал, когда момент настанет. На медвежьем рынке шортов по мемам будет больше.

## Настройки (переменные окружения)

| Переменная | Что | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от @BotFather | (обязательно) |
| `CHAT_ID` | канал: `@имя` или `-100...` | (обязательно) |
| `POLL_MINUTES` | период проверки, минут | 5 |
| `SEND_WATCH` | слать наблюдение (1/0) | 1 |
| `LANG_RU` | язык сообщений (1=рус, 0=англ) | 1 |

## Важно

- Бот **читает** рынок и шлёт сигналы. Он **не торгует** и не управляет деньгами.
- В каждом сигнале есть пометка «Не финансовая рекомендация».
- Движок идентичен сайту — сигналы бота и сайта не будут расходиться.
